# pikapik for Homebrew

Homebrew tap for [pikapik](https://github.com/dev-pikapik/pikapik), a menu bar app for macOS.

## Install

```bash
brew install --cask dev-pikapik/pikapik/pikapik
```

## Update

```bash
brew upgrade --cask pikapik
```

The app also updates itself from its menu.

## Uninstall

```bash
brew uninstall --cask --zap pikapik
```
